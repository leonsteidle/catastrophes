# Historical technical demonstrations

These patchers were developed for the earlier package's bifurcation, hysteresis and multistability demonstrations. Their signal graphs are preserved in this version. Opening an A5 patch with the revised `butterfly~` uses the new solver, so results near repeated roots can differ from earlier runs.

The accompanying files in `audio/` and `figs/` are preserved historical outputs; they have not been regenerated with version 2.0.0. They are not the paired-path and compositional audio examples prepared separately for the revised Computer Music Journal article.

For everyday use, start with `help/`. See `docs/IMPLEMENTATION.md` for object-specific rules and `docs/MIGRATION.md` for the change from the earlier A5.
