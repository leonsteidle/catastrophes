# catastrophes

Max/MSP package: **`catastrophes~`** — René Thom catastrophe models as audio-rate externals (fold~, cusp~, swallowtail~, butterfly~).

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.18166590.svg)](https://doi.org/10.5281/zenodo.18166590)

## Install (Max 8)
Download the latest release (GitHub Releases) and copy the folder `catastrophes~` to:

`~/Documents/Max 8/Packages/`

Then restart Max and open the help patches in `catastrophes~/help/`.
